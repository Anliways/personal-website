# 暗色 UI 的克制美学

暗色主题最容易做「脏」，也最容易做「刺眼」。以下是我在设计系统中沉淀的五个原则。

## 1. 别用纯黑

`#000000` 会让发光元素产生光晕溢出。用 `#121212` 这类深灰做基底，层级之间用 `#1E1E1E → #2C2C2E` 递进。

## 2. 文字别用纯白

纯白文字在暗底上过于刺眼，降到 **87% 不透明度**是更舒服的默认值。

## 3. 层次靠亮度，不靠阴影

暗色模式下阴影几乎不可见，用表面亮度区分层级，再用细边框（`1px, 8% white`）勾勒轮廓。

## 4. 强调色要降饱和

系统蓝 `#0A84FF` 在暗底上已经足够亮，不要再叠加渐变或发光。

## 5. 动效短而缓

200–400ms，缓出曲线。动画的意义是解释「从哪来、到哪去」，不是表演。
